# منصة تبرعات التجمع الطبي في التل — دليل التشغيل

موقع عرض مباشر للتبرعات، يقرأ بياناته من Google Sheets الكود على GitHub، ويُستضاف مجانًا على Cloudflare Pages.

الإعداد لمرة واحدة فقط، ويحتاج حوالي ١٥ دقيقة من **الكمبيوتر** (لأن رفع الملفات وإعداد Google أسهل من المتصفح على اللابتوب).

---

## محتويات المشروع

| الملف | وظيفته |
|---|---|
| `index.html` | الصفحة الرئيسية اللي يشوفها الناس |
| `settings-alsalam.html` | صفحة الإعدادات السرية (محمية بكلمة سر) |
| `_headers` | يمنع محركات البحث من فهرسة صفحة الإعدادات |
| `shamcash.png` | شعار شام كاش |
| `config.js` | فيه رابط الخادم، تعدّله مرة واحدة |
| `logo-white.png` | الشعار الافتراضي |
| `google-apps-script.gs` | كود الخادم، تنسخه إلى Google Apps Script |

## الخطوة 1: تشغيل الخادم على Google (٧ دقائق)

1. افتح [script.google.com](https://script.google.com) بنفس حساب Google اللي رح تعمل فيه الجداول، واكبس **New project** (مشروع جديد).
2. سمّ المشروع `تجمع التل الطبي - الخادم`.
3. امسح كل الكود الموجود، والصق محتوى ملف `google-apps-script.gs` كاملًا، واحفظ (Ctrl+S).
4. **كلمة السر:** من القائمة الجانبية اختر ⚙️ **Project Settings** ← انزل لـ **Script Properties** ← **Add script property**:
   - Property: `ADMIN_PASSWORD`
   - Value: كلمة السر اللي بدك إياها
   - احفظ.
   > بهالطريقة كلمة السر ما بتنكتب داخل الكود، وبتضل آمنة حتى لو الـ repo عام.
5. **منح الصلاحيات:** ارجع للمحرر، ومن القائمة فوق اختر الدالة `authorize` واكبس **Run**.
   - بيطلع لك "Authorization required" ← **Review permissions** ← اختر حسابك.
   - إذا طلعت رسالة "Google hasn't verified this app" ← اكبس **Advanced** ← **Go to تجمع التل الطبي (unsafe)** ← **Allow**.
   - هذا طبيعي، لأن التطبيق تبعك أنت وما في غيرك بيستخدمه.
6. **النشر:** اكبس **Deploy** ← **New deployment** ← أيقونة ⚙️ ← **Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
   - اكبس **Deploy**، وانسخ رابط **Web app URL** (ينتهي بـ `/exec`).

## الخطوة 2: ربط الموقع بالخادم (دقيقة)

افتح ملف `config.js` بأي محرر نصوص، والصق الرابط بين علامتي التنصيص:

```js
window.TAL_CONFIG = {
  SCRIPT_URL: "https://script.google.com/macros/s/XXXXXXXX/exec"
};
```

## الخطوة 3: رفع الكود على GitHub (٣ دقائق)

1. ادخل [github.com](https://github.com) بحساب `alsalam4man` ← **+** ← **New repository**.
2. **Repository name:** `Dr.Tal` ← اختر **Public** ← **Create repository**.
3. اكبس **uploading an existing file**، واسحب **كل الملفات والمجلدات من داخل مجلد المشروع** (مش المجلد نفسه) ← **Commit changes**.

## الخطوة 4: النشر على Cloudflare Pages (٥ دقائق)

1. اعمل حساب مجاني على [dash.cloudflare.com/sign-up](https://dash.cloudflare.com/sign-up) وأكّد الإيميل.
2. من القائمة الجانبية: **Workers & Pages** ← **Create** ← تبويب **Pages** ← **Connect to Git**.
3. اربط حساب GitHub واختر الـ repo `Dr.Tal`.
4. **Project name:** `drtal` (إذا محجوز: `dr-tal`). هذا الاسم هو الرابط.
5. **Framework preset:** None ← **Build command:** فارغ ← **Build output directory:** `/` ← **Save and Deploy**.
6. خلال دقيقة الموقع صار شغّال.

**روابطك:**
- الموقع العام: `https://drtal.pages.dev`
- صفحة الإعدادات: `https://drtal.pages.dev/settings-alsalam`

> من هلأ وطالع: أي ملف بتعدّله أو بترفعه على GitHub، Cloudflare بيحدّث الموقع لحاله خلال ثواني.

## الخطوة 5: إنشاء الجدول (دقيقة)

1. افتح [sheets.new](https://sheets.new) لعمل جدول فارغ جديد، وسمّه مثلًا `تبرعات التجمع الطبي في التل`.
2. انسخ رابطه من شريط العنوان.
3. افتح صفحة الإعدادات ← ادخل بكلمة السر ← الصق الرابط بالقسم 1 ← **إنشاء**.
4. خلال ثوانٍ بيتجهّز الجدول بأربع أوراق منسّقة وجاهزة: **التبرعات المالية**، و**التبرعات العينية**، و**المشاريع**، و**الإعدادات**.

خلص! الموقع صار لايف 🎉

## الاستخدام اليومي

**تسجيل تبرع مالي:** بورقة `التبرعات المالية` أضف سطر فيه التاريخ، واسم المتبرع، والمبلغ، والعملة من القائمة (دولار / ليرة سورية / ريال سعودي). عمود `إظهار` إذا كتبت فيه "لا" بيدخل التبرع بالمجموع بس ما بيظهر اسمه بالقوائم.

**تبرع عيني:** بورقة `التبرعات العينية`: الاسم ونوع التبرع والكمية.

**نسبة المشاريع:** بورقة `المشاريع` اكتب رقمًا من 0 إلى 100، وعند 100 بيظهر المشروع "مكتمل" باللون الأخضر.

**سعر الصرف، الهدف، الواتساب، العنوان، الملاحظة:** من صفحة الإعدادات (القسم 4) أو مباشرة من ورقة `الإعدادات`.

**الشعار:** من صفحة الإعدادات (القسم 3). اختر "لون الشعار: أبيض" ليظهر أبيض فوق الخلفية الفيروزية، أو "أصلي" ليظهر بألوانه.

**صور قبل وبعد:** من صفحة الإعدادات (قسم صور المشاريع) اختر المشروع، واختر "قبل" أو "بعد"، وارفع صورة أو أكثر. الصور بتنحفظ بمجلد "منصة التبرعات - الصور" على الدرايف، وبتنسجل بورقة "صور المشاريع". إذا في صورة قبل بس، بيظهر مكان "بعد" كلمة "قريبًا" بحركة (أو بتختار "بدون" من الإعدادات فتظهر الصورة لحالها).

**شام كاش:** من صفحة الإعدادات (قسم شام كاش) اكتب رقم الحساب وارفع صورة الباركود، فبيظهروا داخل زر "تبرع الآن" مع زر نسخ سريع. وإذا فضّيتهم بيرجع يظهر "قريبًا".

**أكثر من جدول:** الصق رابط جدول جديد واكبس "إنشاء"، وبتقدر تبدّل الجدول المعروض على الموقع من القسم 2.

الموقع بيتحدّث تلقائيًا كل دقيقة عند كل الزوار.

## ملاحظات مهمة

- **تعديل كود الخادم لاحقًا:** بعد أي تعديل على Code.gs روح لـ **Deploy** ← **Manage deployments** ← ✏️ ← Version: **New version** ← **Deploy**. هيك بيضل نفس الرابط.
- **تغيير كلمة السر:** من Project Settings ← Script Properties ← عدّل قيمة `ADMIN_PASSWORD`.
- **الجداول:** لازم تكون بنفس حساب Google اللي نشرت فيه الخادم، أو تكون محرّرًا فيها.
- **تعديل الموقع:** أي ملف بتعدّله على GitHub (زر ✏️) أو بترفعه، Cloudflare بيحدّث الموقع خلال ثواني، وكل نسخة سابقة محفوظة بالـ History.
- **دومين خاص:** إذا اشتريت دومين لاحقًا، بتربطه من مشروع Cloudflare ← Custom domains.
